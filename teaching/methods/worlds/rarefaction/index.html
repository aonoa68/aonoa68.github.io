Rarefaction 希薄化

観察される種類の数は、調べた量に依存して増える。標本サイズの違う集団どうしで種類数を直接比べると、豊富さの差ではなく調査努力の差を測ってしまいます。希薄化は「同じ人数を調べたら何種類出るか」に揃えて比較する手続きです。
小野原が米原〜関ケ原の3世代方言語彙調査で用いた実装に即して、この転用が何を仮定し、どこで成り立たなくなるのかを整理します。

1何のための手法か

豊富さの比較は、標本サイズを揃えないかぎり成立しない。

集団 \(s\) で観察された種類の数を \(S_s\) とする。\(S_s\) は「そこに何種類あるか」ではなく「どれだけ調べたか」に強く依存する。調査した個体を増やせば、それまで出会わなかった種類に出会う機会が増えるので、\(S_s\) は標本サイズ \(N_s\) について単調に増える。したがって \(S_A > S_B\) という観察は、\(N_A > N_B\) であるかぎり豊富さの差の証拠にならない。

この関係は確率的な必然であって、測定の不備ではない。種類 \(i\) が母集団で稀であるほど、小さい標本では見落とされる。標本サイズを増やすと見落としが減る。そのぶんだけ \(S_s\) が増える。観察された種類数は、豊富さと標本努力の積として現れる。

希薄化は、この交絡を計算によって取り除く手続きである。すべての集団について「かりに \(m\) 個体だけを無作為に取り出していたら、何種類が観察されたと期待されるか」を求め、共通の \(m\) の下で比較する。実際に標本を捨てるのではなく、期待値を解析的に計算する。

2起源 ―― どの分野の誰が作ったか

深海底の生物多様性を比べようとして、比べられないことに気づいた研究から。

Howard Sanders が 1968 年に The American Naturalist で提案した。ウッズホール海洋研究所で深海の底生生物群集を扱っており、緯度・水深・水温・塩分の違う環境から採取した試料の多様性を比較しようとしていた。そこで直面したのが前節の問題である。採取した個体数が場所ごとに違えば、種数はそのまま比べられない。Sanders は標本を間引いて共通の大きさに揃えるという発想を持ち込み、これを rarefaction と呼んだ。

Sanders の最初の定式化には計算上の偏りがあり、種数を過大に見積もることが分かった。これを正したのが Stuart Hurlbert（1971、Ecology）である。論文の表題は「種多様性という非概念」で、多様性指数をめぐる当時の議論が意味論的にも技術的にも混乱しているという批判が主題だった。その代替として、生物学的に解釈の定まった量をいくつか提示しており、そのひとつが期待種数である。今日 rarefaction として使われている式は、この Hurlbert の定式化を指す。

手法が、多様性指数への批判として生まれている

この由来は読み方に関わる。Hurlbert が提示したのは「多様性をひとつの数にまとめる」ための指数ではなく、「標本サイズを揃えたうえで種数を数える」という、より素朴で解釈の定まった量だった。希薄化を使うということは、多様性という抽象語を避け、比較可能な条件を作ってから数えるという立場を採ることでもある。

3数学的にどこから来ているか

超幾何分布。17〜18世紀の組み合わせ論がそのまま使われている。

\(N\) 個体のうち種類 \(i\) に属するものが \(N_i\) 個体あるとする。ここから \(m\) 個体を非復元で無作為に取り出したとき、取り出した \(m\) 個体のなかに種類 \(i\) が1個体も含まれないのはどういう場合か。それは、種類 \(i\) 以外の \(N-N_i\) 個体だけから \(m\) 個体を選んだ場合である。

種類 \(i\) を1個体も引かない確率
\[ \Pr\bigl(\text{種類 } i \text{ が標本に現れない}\bigr) \;=\; \frac{\dbinom{N-N_i}{m}}{\dbinom{N}{m}} \]

分母は \(N\) 個体から \(m\) 個体を選ぶ総数、分子はそのうち種類 \(i\) を避けた選び方の数。これは超幾何分布で 0 個を引く確率にあたる。「赤玉と白玉の入った袋から \(m\) 個取って赤玉が何個か」という古典的な問いと同じ構造である。

余事象を取れば、種類 \(i\) が標本に少なくとも1個体は現れる確率になる。求めたいのは観察される種類の総数の期待値なので、指示変数の和として書き、期待値の線形性で足し合わせればよい。

Hurlbert（1971）の期待種数
\[ \mathbb{E}\bigl[S_m\bigr] \;=\; \sum_{i=1}^{S} \left[\, 1 - \frac{\dbinom{N-N_i}{m}}{\dbinom{N}{m}} \,\right] \]

\(S\) … 全標本で観察された種類の総数
\(N\) … その集団の標本サイズ、\(N_i\) … 種類 \(i\) の個体数、\(m\) … 揃える深さ
期待値の線形性 … 種類ごとの出現確率を単に足している。種類どうしの独立性は仮定していない

シミュレーションではなく、閉じた式である

「標本をランダムに間引いて数える」という操作を繰り返し実行して平均を取っても同じ値に近づくが、その必要はない。上の式は期待値そのものを与える。実装上は \(\binom{N-N_i}{m}\big/\binom{N}{m}\) を対数で計算して指数を取る（exp(lchoose(N-k, m) - lchoose(N, m))）のが安定で、\(N-N_i < m\) のときは自動的に 0 になり、その種類の寄与が 1 になる。

4言語研究への転用 ―― 何を読み替えているか

生態学の「個体」と「種」を、言語調査の「話者」と「語彙項目」に置き換える操作である。

文化進化の研究では、集団規模と文化的多様性の関係が主題になることが多い。語彙についても「大きい集落ほど語彙が豊富か」という問いが立てられる。ここで観察される語彙項目数は、生態学における種数と同じ構造の問題を抱えている。大きい集落ほど多くの話者を調査できるので、項目が多く観測される。

読み替えの対応

採取した個体数 \(N\) → 調査した話者数
種類 \(i\) の個体数 \(N_i\) → 語彙項目 \(i\) を使用すると答えた話者数 \(k_i\)
観察された種数 \(S_m\) → \(m\) 人を調べたときに出現すると期待される語彙項目数
式の形は変わらない。\(N_i\) を \(k_i\) と読み替えるだけである。

ひとつ、構造が違う点がある

生態学の設定では、1個体は1つの種にしか属さない。したがって \(\sum_i N_i = N\) が成り立つ。ところが言語調査では、1人の話者が多数の語彙項目を使う。この研究の場合、106 項目に対して1人が何十項目も「使う」と答えるので \(\sum_i k_i \gg N\) である。

式そのものは破綻しない。上の導出が使っているのは「\(m\) 人のなかに項目 \(i\) の使用者が1人も含まれない確率」だけであり、話者が他の項目も使うかどうかには依存しないからである。生態学でも、個体ではなく標本単位の出現・非出現を数える形（incidence-based / sample-based rarefaction）として確立した使い方にあたる。

ただし解釈は変わる。得られる量は「\(m\) 個体を採取したときの期待種数」ではなく「\(m\) 人に尋ねたときに少なくとも1人が使うと答える項目の期待数」である。個体数に基づく希薄化の直感をそのまま持ち込むと、この違いを見落とす。

5この研究での使い方

人口規模と語彙の豊富さの相関が、標本努力の産物かどうかを確かめる。

  1. 個人データの復元　集計表ではなく個人単位の回答が必要なので、原データの全体シートから中学生の個票を復元する。実在する中学校名・学年 1〜3・語彙回答がすべて 0/1/2 のいずれか、という条件で 510 人・49 集落を抽出し、値が 2（「使う」）のものを使用とみなす。
  2. 使用行列の構成　106 の語彙項目について、集落ごとに調査人数 \(N\) と、項目 \(i\) の使用者数 \(k_i\) を数える。系統別（関西・近江系／東京・標準系／美濃・尾張系）にも同じ集計を作る。
  3. 生の豊富さ　\(k_i > 0\) である項目の数を数える。これが補正前の richness。
  4. 希薄化した豊富さ　Hurlbert の式で \(\mathbb{E}[S_m]\) を計算する。深さは \(m = 3,\,5,\,8\) の3通りを試す。\(N < m\) の集落は計算できないので除外する（\(m=3\) で 37 集落、\(m=5\) で 29 集落が残る）。
  5. 人口との回帰　生の豊富さと希薄化した豊富さのそれぞれを、集落人口の常用対数に回帰し、傾きを比べる。
系統生の豊富さ希薄化 \(m=3\)希薄化 \(m=5\)
総項目数+21.0〜+21.5 (p<.001)−4.3 (p=.21)−2.4 (p=.49)
関西・近江系+10.3〜+11.5 (p<.001)−2.8 (p=.23)−3.3 (p=.22)
美濃・尾張系+8.5〜+13.4 (p<.01)−1.3 (p=.55)+0.6 (p=.81)
東京・標準系+0.7〜+0.8 (p<.03)−0.3 (p=.38)+0.1 (p=.68)

集落人口の常用対数に対する回帰の傾き。数値は解析スクリプトの実行結果を作業記録から引用したもの。生の側に幅があるのは、系統分類の版によって値が動くため。

補正すると、関連は消えてわずかに負へ転じる

生の豊富さでは、人口の対数に対する傾きが総項目数で \(+21\) 前後、いずれも \(p<.001\) と強い正の関連が出る。ところが標本サイズを揃えると、すべての系統で有意でなくなり、符号も安定しない。\(m=3\) と \(m=5\) で結論は一致している。「人口が大きい集落ほど語彙が豊富」という観察は、大きい集落ほど多くの中学生を調査したという標本努力の差でほぼ説明される。

同じ結論が、独立な二つ目の経路からも得られている。希薄化のように標本を物理的に揃えるのではなく、階層モデルに調査人数の対数を共変量として入れて統制する方法でも、関西系の人口効果は \(-0.07\) まで落ちる。手続きの違う二つの方法が同じ向きの結論に収束していることが、この判断の根拠になっている。

6限界 ―― この手法で言えないこと

標本努力を揃えても、測定の上限までは取り除けない。

固定リスト調査では、天井が効く

ここが最も重い制約である。生態学の設定では、観察されうる種数に人為的な上限がない。採取を増やせば新しい種が出てくる余地が常に残っている。ところがこの調査はあらかじめ用意された 106 項目のチェックリストで行われている。豊富さの上限は 106 であり、それ以上は原理的に増えない。

語彙変異が実際に豊かな集落ほど、リストが埋まりきる方向に近づく。すると本当の差がリストの上限で圧縮される。100 問のテストで実力差を測るとき、上位層が揃って満点に近づけば差が見えなくなるのと同じ構造である。希薄化は標本努力の交絡を取り除くが、この天井には何もしない。

したがって、この研究の結論は「固定リスト調査では、richness を語彙多様性の指標として使えない」という否定形になる。人口と多様性のあいだに関連がないことを示したのではなく、この測定方法では関連の有無を判定できないことを示している。両者は別の主張である。

読み替えが持ち込む仮定

第4節で述べたとおり、話者は個体と違って多数の項目を同時に使う。加えて、生態学の希薄化は個体が母集団から無作為に抽出されることを前提とするが、この調査は地域を単位に実施されており、世帯内の非独立性を排除できない。同じ世帯の中学生どうしは語彙を共有しやすい。有効な標本サイズは \(N\) より小さい可能性があり、その場合、希薄化した値の不確実性は見かけより大きい。

復元データそのものへの留保

希薄化には個人単位のデータが要るため、集計済みの原資料から個票を復元している。この復元で得た豊富さは原著の値と完全には一致せず、相関は 0.64 である。差の原因は項目分類と使用判定の閾値の定義差にあり、データの誤りではないことが確認されている。生の豊富さと希薄化した豊富さの比較は同一の復元データ内での比較なので結論は内的に妥当だが、原著の個人集合そのものを特定できれば確度は上がる。

7出典とデータ

滋賀県米原市から岐阜県関ケ原町にかけての5中学校区を対象とした、3世代方言語彙調査の二次解析である。調査票は 40 の質問概念で 106 の方言語彙変異を引き出しており、関西・近江系 45、東京・標準系 31、美濃・尾張系 26 に若者語・新方言 4 項目を加えて事前分類されている。原調査は 2015 年にはびろネットが実施し、本研究はその匿名化データを解析したもの。解析は全工程がスクリプト化されており、原データファイルは改変せず作業コピー経由でのみ読んでいる。

この手法がどの観点に属するか

希薄化が扱っているのは、標本の取り方によって統計量がどう変わるかという問題そのものである。母集団の量は固定されたものと見て、標本サイズを揃えることで観測量の比較可能性を回復させる。分布の形を仮定せず、組み合わせ論から期待値を直接計算する点で、7つの観点を式で読むの観点2（頻度論）に重なる。Mantel 検定が並べ替えで帰無分布を作るのと同じく、標本の側を操作して判断の基準を作る発想にあたる。

このページは、小野原が実際の研究で使っている手法を、同じ分野の読み手に向けて整理したものです。数値はすべて解析スクリプトの出力と作業記録から引用し、推定値や概算は記載していません。
手法の位置づけの全体像は 7つの観点を式で読む、どの授業回がどの観点に当たるかは 手法と数学の地図 にあります。
