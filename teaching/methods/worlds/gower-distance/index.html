Gower's Distance

アクセント型のような名義尺度のデータから距離を作る手続きです。「合っているか、合っていないか」だけを数え、合致率を 1 から引いたものを距離とします。
小野原の博士論文（2013年度）第6章 事例4 で、岐阜県旧徳山村のアクセント体系を数値化する入口に置かれている手続きです。何が測れていて、何が測れていないのかを、論文に印刷された数値に即して整理します。

1何のための手法か

アクセント型という、足し算も引き算もできないデータを、比較できるひとつの指標に合成する。

手元にあるのは、地点ごとのアクセント型の記述である。「柄・蚊・血」の型は、本郷で HHH~HHL、戸入で HH~LH、東京式で LH、京阪式で HHH のように、高拍（H）と低拍（L）の並びとして書かれている。問いは、この地点とあの地点は、どれくらい違うのかという一点にある。

この記述は、そのままでは比べられない。セルによって拍数が違い、\(\sim\) を挟んで2つの型が併記されている場合もあり、1つの地点は15個のセルに分かれている。論文はここを「地点同士のすべてのアクセント情報同士を比較する必要があり、そのときにすべて同じ基準でひとつの指標に合成する必要があるため」と述べ、15個のセルから作った一連のパターンを距離に置き換えるという方針を取る。

なぜ距離の測り方をわざわざ選ぶ必要があるのか。名義尺度、すなわち大小も間隔も定義されていない尺度では、カテゴリに数値を割り当てても、その数値に意味がないからである。仮に型そのものを1つのカテゴリとして扱うなら、\(\text{HHH}\) に 1、\(\text{HHL}\) に 2、\(\text{LHH}\) に 3 と振っても、「\(\text{LHH}\) は \(\text{HHH}\) の3倍」でも「\(\text{HHL}\) は両者の中間」でもない。割り当て方を変えれば距離が変わってしまう以上、出てきた数値は手法の出力ではなく符号化の副産物になる。Gower 距離が見るのは一致しているか否かだけなので、ラベルの付け方に結果が依存しない。

このデータに限れば、ユークリッド距離でも順序は変わらない

ただし正確に言えば、この研究が最終的に採った符号化は2値である。論文は「パターンの H を 1、L を 0 として、2 値の変数に変換した上で」daisy に渡したと明記している。値が2つしかない変数では、1 と 0 の割り当ては恣意的ではなく、ユークリッド距離も意味を持つ。

実際、52 個の位置のうち不一致の数を \(m\) とすると、ユークリッド距離は \(\sqrt{m}\)、Gower 距離は \(m/52\) であり、どちらも \(m\) の増加関数なので、地点の並び順は同じになる。このデータでユークリッド距離を使っても結論は変わらない。

では Gower 距離を使う意味はどこにあるのか。(1) 値が 0 から 1 に正規化され、「何割の位置で食い違うか」として読めること。(2) カテゴリが3つ以上ある場合、欠測がある場合、量的変数と名義変数が混在する場合にそのまま拡張できること。この研究は (1) の利点を使っており、(2) は使っていない。手法の一般性と、この適用事例で実際に効いている部分は別である。

2定義

変数ごとに一致度を決め、その平均を 1 から引く。

Gower (1971) が提案した係数は、変数の型が混ざっていてもよいことを目的に設計されている。2つの対象 \(i, j\) と \(p\) 個の変数について、変数ごとの類似度 \(s_{ijk}\) と、その変数を比較に使うかどうかを表す重み \(w_{ijk}\) を定め、重み付き平均を取る。

一般形の Gower 係数と、そこから作る距離
\[ S_{ij} \;=\; \frac{\sum_{k=1}^{p} w_{ijk}\, s_{ijk}}{\sum_{k=1}^{p} w_{ijk}}, \qquad d_{ij} \;=\; 1 - S_{ij} \]

\(s_{ijk}\) … 変数 \(k\) における一致度。名義尺度なら一致で 1、不一致で 0。量的変数なら値域 \(R_k\) で割った \(1 - |x_{ik}-x_{jk}|/R_k\)。順序尺度なら順位に直してから同様に扱う
\(w_{ijk}\) … どちらかが欠測なら 0、比較できるなら 1。分母が「実際に比べられた変数の数」になる
\(d_{ij}\) … 1 から類似度を引いたもの。0 なら全変数が一致、1 なら全変数が不一致

一般形の記述は手法の標準的な定式化による。論文に書かれているのは、次に示す名義尺度の場合だけである。

この研究で使われたのは、すべての変数が同じ型で、欠測がない場合である。このとき \(w_{ijk}\) はすべて 1 になり、式は次のように縮む。

この研究で使われた形
\[ d(x, y) \;=\; 1 - \frac{1}{p}\sum_{k=1}^{p} \mathbf{1}\!\left[\, x_k = y_k \,\right] \;=\; 1 - \frac{\text{合致数}}{\text{全体数}} \]

論文はこれを次のように定義している。「Gower's Distance とは、名義尺度データ同士の組み合わせの合致率を元に算出する距離であり、ある行とある行の要素の組み合わせの合致数を行全体の要素数で割り、1 から引いた値である。」

2値変数では、名義として扱っても量的として扱っても同じ値になる

H を 1、L を 0 に直した2値変数では、名義尺度としての一致度（一致なら 1）と、値域 \(R_k = 1\) の量的変数としての一致度 \(1 - |x_{ik}-x_{jk}|/1\) が完全に一致する。したがって、daisy が列を factor と見るか numeric と見るかに関わらず、同じ距離が出る。この研究の符号化では、列の型宣言が結果を左右しない。

この特殊形は、単純一致係数（simple matching coefficient）の補数であり、長さで割ったハミング距離に等しい。つまりこの研究で行われている計算そのものは、Gower の一般形が持つ「型の混在への対応」を使っていない。使われているのは一般形のうち一致・不一致の枝だけである。

3データをどう作ったか

アクセントの「揺れ」と「併存」を、ありうる型の全組み合わせに展開する。

入力は表6-1「名詞（+助詞）アクセントの型（老年層）」である。一拍名詞3類・二拍名詞5類・三拍名詞7類の計15類について、格助詞「が」を後接させた型が H と L で書かれている。論文の説明によれば、これは野村 (1977) の論文中に併せて記載のある杉戸の報告であり、本郷・戸入・塚のアクセント体系に、金田一 (2003) p.71 から引いた東京式・京阪式を付け加えたものである。

  1. 調査時期　1971年および1976年。
  2. 対象　徳山村8集落のうち、本郷・門入・櫨原・塚・戸入の5集落。表中に門入と櫨原の記載がないのは、本郷と同じアクセント体系であるためと論文が明記している。
  3. インフォーマント　老年層で、各集落最低2名。
  4. 分析項目　1拍から3拍の名詞。

ここで問題になるのが、表の中に「\(\text{LHL} \sim \text{HLL}\)」のように2つの型が併記されたセルがあることである。論文は2種類を区別して説明する。\(\sim\) の左右の関係は音声的な揺れ、同じセル内に上下に並べて書かれた関係は併存（杉戸の用語では、揺れよりも強固にその型の発音が見られる場合）である。

なぜ展開する必要があるのか

併記されたセルを1つの記号としてそのまま扱うと、「\(\text{LHL} \sim \text{HLL}\)」は「\(\text{LHL}\)」とも「\(\text{HLL}\)」とも別のカテゴリになる。名義尺度では部分一致という概念がないので、揺れを持つ地点は、揺れの片方と完全に一致する地点に対しても「不一致」になってしまう。揺れの幅が広い地点ほど他のどの地点からも遠く出るという、記述の書き方だけで決まる結果が生じる。

論文が挙げる理由はこれより一段手前にある。「なぜなら、地点同士のすべてのアクセント情報同士を比較する必要があり、そのときにすべて同じ基準でひとつの指標に合成する必要があるためである。」併記されたセルを「その地点で話されていた可能性のある型の集合」と読み直し、拍数ごとに各類が取りうる型を1つずつ選んだ組み合わせをすべて作れば、地点は1本の文字列ではなく文字列の集合として同じ形式で表せる。

揺れと併存を区別せず並列に扱った理由も明記されている。「インフォーマント間で揺れるのか、一人のインフォーマントに何度か同じ語を発音してもらった時に揺れるのか、同じ語類の中で同一人物の発音が揺れるのかは不明であり」、かつ杉戸のいう併存との違いが「明確ではないため」である。区別できるだけの情報が元の記述にないから、区別しないという判断である。

組み合わせ数

本郷について、論文は数え上げを具体的に示している。一拍名詞の3類は表6-1 で \(\text{HHH} \sim \text{HHL}\) / \(\text{HHL}\) / \(\text{HHL} \sim \text{LHH}\) なので、取りうる組み合わせは次の 4 パターンになる。

HHH/HHL/HHL
HHH/HHL/LHH
HHL/HHL/HHL
HHL/HHL/LHH

同様に二拍名詞だけの組み合わせが 6 パターン、三拍名詞だけの組み合わせが 16 パターンで、\(4 \times 6 \times 16 = 384\) パターンとなる。塚は 1024 パターン、戸入は 4608 パターンである。塚と戸入については、拍数ごとの内訳は論文に記載がない。

符号への置き換え

15類すべてをつないだ1パターンは、H と L からなる52 文字の文字列になる。52 という長さは、表6-1 から直接確かめられる。一拍名詞は3類 × 3拍、二拍名詞は5類 × 3拍、三拍名詞は7類 × 4拍であり、\(9 + 15 + 28 = 52\) である。

そのうえで論文は「パターンの H を 1、L を 0 として、2 値の変数に変換した上で」daisy に渡している。比較の単位は「語（類）」ではなく「拍」である。この粒度の選択が、第6節で見るように値そのものを左右する。

なお、同じ分析を口頭・ポスターで発表した資料では、元の表記（\(\bullet\) 高拍・\(\blacktriangledown\) 長音化した第2拍・\(\circ\) 低拍・拍無し）を a / b / c / 0 の4値に置き換えたと説明されている。博士論文の版は H / L の2値であり、\(\blacktriangledown\) は高拍として H にまとめられている。掲載されている距離行列の値は両者で同じである。

4実際の計算

52 個の位置を並べて、合っている数を数えるだけである。

論文は、本郷の第1パターンと第2パターンを例に挙げている。この2本は最後の2文字だけが異なる。

論文に印刷されている計算
\[ \text{全体の数} = 52, \qquad \text{合致数} = 50, \qquad d = 1-\frac{50}{52} = 0.038 \]

「52 の要素があり、そのうち最後の 2 つの要素だけが異なる。すなわち合致数は 50 であるから、Gower's Distance は、1-(50/52)＝0.038 という値になる。」\(1 - 50/52 = 0.03846\ldots\) であり、後述する表6-2 の 本郷1–本郷2 の値 0.038 と一致する。最適化も反復計算もない。

最も遠い組も、同じ式で追える

表6-2 で最大の値は 本郷1–戸入4608 の 0.538 である。定義から逆算すると、\(1 - m/52 = 0.538\) を満たす合致数は \(m = 24\) であり、52 個の位置のうち 24 個で一致し、28 個で食い違っていることになる。\(1 - 24/52 = 0.53846\ldots\) で、印刷値 0.538 と一致する。

本郷1 と本郷2 は 50/52 が一致し、本郷1 と戸入4608 は 24/52 しか一致しない。この2つの数の対比が、そのまま「同じ集落の中の揺れ」と「集落をまたいだ体系の違い」の対比になっている。

同じ例は 2012 年の発表資料でも報告されているが、計算例の書き方が異なる。このページの数値と式は、すべて博士論文（第6章 事例4）の記述に依拠している。

5Rでの実行

cluster パッケージの daisy に metric="gower" を渡すだけである。

論文は「統計解析ソフト R のパッケージ cluster の関数 daisy にて Gower's Distance を算出した」と述べている。同じ分析の発表資料には、実際のスクリプトが5行で示されている。data は、全パターンを1行1パターン・1列1拍に並べ、H を 1・L を 0 に直した表である。 

library(cluster)
dgower <- daisy(data,  metric="gower")
mgower=as.matrix(dgower)
diag(mgower) <- 0
write.csv(mgower,file="goweracc.csv")

この5行が何をしているか

daisy は距離オブジェクトを返す関数で、metric="gower" を指定すると第2節の一般形で距離を計算する。列の型が計算式を決めるのが daisy の設計だが、第2節で見たとおり2値の列ではどちらの扱いでも同じ値になるので、ここでは型宣言が問題にならない。

as.matrix で対称行列に直し、diag に 0 を代入して対角成分を明示的に揃え、CSV に書き出している。

行数は本郷 384 ＋ 塚 1024 ＋ 戸入 4608 で 6016 になる。したがって出力は 6016 × 6016 の距離行列である。

6結果

パターン間の距離をまず出し、それを集落ごとに平均して集落間の距離とする。

戸入が遠いとは、どういうことか

旧徳山村の集落のうち、戸入だけが乙種（東京式）のアクセントを持ち、本郷ほかは甲種（京阪式）、塚は中間型とされてきた。論文は表6-4 の数値をこうまとめている。「本郷その他（本郷、櫨原、門入）と塚の言語距離が 0.260、本郷と戸入が 0.475、戸入と塚が 0.393 である。」

本郷–戸入が最大で、塚はその間に入る。論文はこの表を計量的 MDS（R の cmdscale）で図示し（図6-6）、「塚のアクセントは、本郷その他と戸入の中間に位置することがわかる」と述べている。従来「中間型」と呼ばれてきたものが、実際に数直線上の中間にあることが示されたという読みである。

ただしこれは既知の分類の追認でもある。順序が入れ替わるような結果ではない。論文の言い方も「情報を数値に縮約しても、戸入、塚、本郷のアクセント様相の違いを示すことができた」という、控えめなものである。

地理的距離と並べる

この言語的距離は、交通路のある地点の組み合わせについて、地理的距離と対比される。地理的距離は次の式(1)で定義されている。

式(1)　地点間の距離
\[ \sqrt{\bigl(\text{地点間のユークリッド距離}(m)\bigr)^{2} + \bigl(\text{標高差}(m)\times 8.3\bigr)^{2}}\;\;(m) \]

垂直距離を水平距離の 8.3 倍にしているのは、「一般的に人間は 1 時間に 5km 歩くことができ、標高が 600m 上がるごとにそこに 1 時間加える」ことが知られているためだと論文は説明している（cf. Langmuir 1984）。直線距離ではなく、歩く労力に近づけた距離である。

下開田 — 本郷9510.113
塚 — 櫨原17610.26
山手 — 本郷24000.113

表6-5 より、印刷されたとおりに引用（塚–櫨原の言語的距離は 0.26 と表記されている）。同じ対比表は発表資料にも載っているが、そちらの地理的距離は 658 / 951 / 1742 / 2365 / 2516 / 3541 / 4709 であり、値が異なる。発表資料の式には標高差の 8.3 倍という重みがなく、標高差をそのまま足していたためと読める。言語的距離の側は両者で同じである。

式(1) が 682 m でも 2516 m でも、言語的距離は同じ 0.113 である。これは言語的距離が3つの体系の区別しか持っていないことの直接の帰結である。同じ体系で記述された地点どうしの距離は 0 ではなく 0.113 になり、地理的にどれだけ離れていてもその値のままになる。論文は「櫨原、山手、本郷、上開田、下開田がその地理的距離に関わらず、言語的距離で同値を示すのは、地理的要因以外の働き、例えば交通量によるものと推測され、その要因の抽出は今後の課題としたい」と述べている。

この章ではさらに、近世の僧侶の巡回路から復元した44地点のネットワーク（R の sna パッケージ、重みは式(1)）について媒介中心性が計算され、戸入 84.000、塚 183.667、上開田 164.000 と、本郷 437.333 や櫨原 494.333 に比べて低いことが示されている。言語的に遠い地点が、交通網の上でも経路になりにくい地点だったという対応である。ただしこの媒介中心性は交通網の側の指標であり、Gower 距離から計算されたものではない。

同じ対象を、別の粒度で符号化した場合

英語で発表された同じ研究では、符号化の単位が違う。拍ではなく15の類を1変数とし、各類の型に A・B・C… の文字を割り当てている。1パターンは52文字ではなく15文字になる。この符号化での計算例は「West1 と East4606 で \(1-3/15 = 0.8\)」である。

3系統間の距離行列は次のとおりである。West（甲種）内 0.2777778、Middle（中間型）内 0.3333333、East（乙種）内 0.3794667、West–Middle 0.4444444、West–East 0.8462049、Middle–East 0.7077812。結論のスライドでは 0.278 / 0.333 / 0.380 / 0.444 / 0.846 / 0.708 と丸めて示されている。

大小の順序は拍単位の結果と一致する（West–East ＞ Middle–East ＞ West–Middle、博士論文の拍単位では 0.475 ＞ 0.393 ＞ 0.260）。しかし絶対値は倍近く違う。類単位では、その類の中の1拍でも違えばその類全体が「不一致」になるため、不一致が積み上がるからである。この比較は第7節の限界に直結する。

7限界

値は必ず 0 と 1 の間に出る。出たからといって、意味があるとは限らない。

展開した全パターンを等重みで平均している

384・1024・4608 は「ありうる型の組み合わせ」の数であって、それぞれが実際に同じ頻度で話されたという根拠はない。揺れの正体が不明であることは論文自身が明記している——インフォーマント間の揺れなのか、同一話者の反復発話の揺れなのか、同じ語類の中の揺れなのかは分からない、と。にもかかわらず集落間平均は、全パターンが等確率だという仮定を暗黙に置いている。

さらに、パターン数が集落ごとに大きく違う（384 : 1024 : 4608）。本郷と戸入の平均は \(384 \times 4608\) 個のセルの平均、本郷と塚の平均は \(384 \times 1024\) 個のセルの平均であり、平均の取られ方が組ごとに違う。距離の値のうちどれだけが言語の違いで、どれだけが記述に含まれる揺れの量の違いなのかは、この手続きでは分離できない。

対角成分（本郷ほか 0.113、塚 0.240、戸入 0.240）は、集落内のパターン同士の平均であり、その集落の記述に含まれる揺れの大きさをそのまま表している。集落間の値と同じ表に同じ尺度で並んでいるが、測っているものが違う。論文がこの数値を「疑似的な言語距離」と呼んでいるのは、こうした留保を含んだ表現だと読める。

合致か不一致かの二値化で、「近い型」と「遠い型」が区別できない

拍単位の 0/1 に直した時点で、残るのは「何個の拍で食い違うか」だけになる。\(\text{HHLL}\) と \(\text{HLLL}\)（2拍目だけ違う）も \(\text{HHLL}\) と \(\text{HHHL}\)（3拍目だけ違う）も、等しく「不一致1」である。アクセント核が語頭側にずれたのか語末側にずれたのかという、変化の方向は距離に入らない。類単位で符号化した英語版では、この区別はさらに失われ、どちらも「その類は不一致」の1カウントになる。

この点は論文自身が今後の課題として挙げている。「いわゆる乙種（東京式）、甲種（京阪式）の単純な対立ではなく、拍ごとや類ごとに両者の特徴が入り混じるのが方言の通常の様態であるため、それらの細かい変化と変化の方向に注目することが今後、必要になると思われる。」1つの距離に合成するという操作が、まさにその「入り混じり」を潰している。

変数間の相関を無視している

52 個の位置は独立ではない。同じ語の隣り合う拍は音韻的に強く依存し、同じ類に属する語は定義上まとめて動く。Gower 距離はすべての変数を等重みで単純平均するので、連動して動く変数が多い部分ほど、その部分が実質的に重く効く。三拍名詞は7類 × 4拍で 28 個の位置を占め、52 個の過半である。それが妥当な重みづけであるという根拠は示されていない。

Gower (1971) の一般形には変数ごとの重み \(w_{ijk}\) があるが、この研究で重みを調整したという記述はない。既定の等重みがそのまま使われていると読める。対応分析のカイ二乗距離が周辺度数で重み付けを行うのと対照的で、Gower 距離には「どの変数を重く見るか」という機構が入っていない。

値そのものに絶対的な意味はない。符号化の設計で変わる

同じ対象・同じ手法でも、博士論文の拍単位（52変数）では甲種–乙種が 0.475、英語発表の類単位（15変数）では 0.8462049 になる。順序は保たれるが、数値は倍近く違う。したがって「0.5 以上なら別系統」といった閾値的な解釈は、この距離には与えられない。

比較できるのは、同じ符号化のもとで計算された値どうしだけである。他の研究の Gower 距離や、他の距離尺度の値と直接並べることはできない。

データの規模が小さい

アクセントの記述は、杉戸の報告に基づく3つの体系（本郷・塚・戸入）しかない。門入と櫨原は本郷と同じ体系として扱われているため、表6-4 の 5集落のうち3集落は完全に同じ行になる。表6-5 に現れる山手・上開田・下開田も、同じ理由ですべて 0.113 である。5×5 の表に見えるが、独立な情報は 3×3 しかない。

インフォーマントは老年層で各集落最低2名、調査時期は1971年および1976年である。比較に用いた語彙は一拍名詞3類・二拍名詞5類・三拍名詞7類の計15類で全体系に共通しており、この点では揃っている。ただし、この15類がアクセント体系全体をどれだけ代表しているかは資料からは判断できない。また、各集落2名前後の発話から得られた揺れの記述が、集落の言語をどれだけ代表しているかも判断できない。

距離であって、統計モデルではない

Gower 距離には確率モデルがない。したがって標準誤差も信頼区間も検定も伴わない。0.475 と 0.393 の差が意味のある差なのか、パターン展開の仕方を少し変えただけで消える差なのかは、この手続きだけでは判断できない。

この研究では、その判断を距離の内部ではなく外部に求めている。近世の巡回路から復元した交通網の媒介中心性、坂内村との婚姻関係、先行研究が記述してきたアクセント体系といった別の種類の情報と突き合わせ、戸入の孤立が複数の指標で同時に現れることを確認するという構成である。距離そのものの不確実性を評価する手続きは含まれていない。

この手法がどの観点に属するか

Gower 距離は、モデルを立てて推定する手続きではない。名義尺度のデータに対して距離空間そのものを構成する手続きであり、その意味で分析ではなく分析の前段にある。7つの観点を式で読むの観点1（幾何・最小二乗）に属するのは、この段階で「何をもって近いとするか」という幾何が決まるからである。

この章でも、Gower 距離は入口に置かれている。表6-4 の集落間距離がそのまま計量的 MDS（図6-6）の入力になり、ネットワーク図（図6-8 上）のエッジの重みになる。距離の定義を変えれば、その先の答えはすべて変わる。距離を入力に取る手法は例外なくこの段階の設計に乗っており、Neighbor-Net が距離行列から分岐構造を描くのも、計量的 MDS が距離を座標に直すのも、同じ依存関係にある。

ただし、この章のすべてが Gower 距離の上に乗っているわけではない。媒介中心性は交通網の側の指標で、重みは式(1) の地理的距離である。対応分析も、隣接する第7章で人口密度や慣習のデータに適用されており、アクセントの距離とは別の入力を持つ。2つの系列は直列ではなく並列に置かれ、同じ結論に別経路で到達するかどうかを見る構成になっている。距離は万能の入口ではなく、その距離で測れるものの入口である。

このページは、小野原が実際の研究で使っている手法を、同じ分野の読み手に向けて整理したものです。数値はすべて出典に印刷された値から引用し、推定値や概算は記載していません。複数の資料で記述が食い違う箇所は、博士論文の記述を採り、その旨を明記しています。
距離を入力に取る手法については Neighbor-Net と 対応分析、手法の位置づけの全体像は 7つの観点を式で読む、どの授業回がどの観点に当たるかは 手法と数学の地図 にあります。
