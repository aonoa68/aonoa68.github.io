Apparent-time Method

言語変化を調べたいが、同じ話者を数十年追うことはできません。いま同時に測った世代差を、過ぎた時間の代用として読む。それが見かけ上の時間法です。代用が成り立つかどうかはデータの外側にある仮定に委ねられ、そこにこの手法の力と弱さの両方があります。
小野原が米原〜関ケ原の3世代方言語彙調査で用いた実装に即して、何を仮定し、何を主張できるのかを整理します。

1何のための手法か

「この方言語彙は失われつつあるのか」を、1回の横断調査から問う。

言語変化を直接測るなら、同じ話者集団を時点 \(t_1\) と \(t_2\) で二度調べればよい。これをリアルタイム調査という。方法としては最も素直だが、数十年の待ち時間が要り、その間に対象者は移動し、亡くなる。調査設計としてほとんど実行できない。

見かけ上の時間法は、この時間軸を世代軸に置き換える。1時点の調査で高年世代と若年世代を同時に測り、高年世代の言語を過去の状態の近似、若年世代の言語を現在ないし未来の状態の近似として読む。世代間の差を、経過した時間の差として解釈する。

この操作が成立するかどうかは、観測からは決まらない。世代差というひとつの観測に、時間変化という別の解釈を重ねる操作であり、観察データから変化の向きを語ろうとする点で因果推論の問題にあたる。第6節で述べるとおり、この手法の限界もそこから来る。

2起源

William Labov が、変化の途中を捉えるために立てた枠組み。

1963年、Labov はマサチューセッツ州マーサズ・ヴィンヤード島で二重母音 /aɪ/ /aʊ/ の第一要素の位置が動いていることを報告した。島の住民を地域・年齢層・職業・民族で分け、変異の分布を調べることでこの音変化の最近の歴史を再構成できるという立論である（Labov 1963）。年齢層ごとの分布を時間軸として読む発想がここにある。

以後、Labov は1966年のニューヨーク市の音変化研究、1994年から2010年にかけての『言語変化の原理』全3巻を通じて、変異社会言語学という分野そのものを立ち上げた。見かけ上の時間法はその中核的な道具として定着し、方言研究で広く使われている。

「変化の途中」を観測できるという主張

この手法が前提にしているのは、言語変化が集団の中で一様に進むのではなく、世代という層を持って進むという見方である。変化が完了していれば世代差は消え、変化が始まっていなければ世代差は現れない。世代差が観測されるのは変化が進行中のときだけだ、という理屈になっている。

3数学的にはどこから来ているか

手法そのものに固有の数学はない。数学が入るのは、世代差を測る側である。

見かけ上の時間法は、統計手法というより調査設計上の読み替えである。世代差を時間差として解釈してよい、という仮定を置くこと自体に数式はない。数学が必要になるのは、その世代差をどう測り、どう検定するかという段階からである。

この研究では、世代ごとの使用割合の差を消失・獲得として定義し、その割合をベータ回帰でモデル化している。割合を扱うベータ分布は指数型分布族に属し、一般化線形モデルの枠組みで線形予測子と結ばれる。つまり数学的なルーツは、見かけ上の時間法の側ではなく、指数型分布族と一般化線形モデルの側にある。

世代差から消失・獲得を作る
\[ \mathrm{loss}_s = \frac{1}{J}\sum_{j=1}^{J}\max\bigl(g_{sj}-m_{sj},\,0\bigr), \qquad \mathrm{gain}_s = \frac{1}{J}\sum_{j=1}^{J}\max\bigl(m_{sj}-g_{sj},\,0\bigr) \]

\(g_{sj}\) … 集落 \(s\) で項目 \(j\) を使う高年世代（60歳以上）の割合
\(m_{sj}\) … 同じ項目を使う中学生の割合
\(J\) … 両世代にデータのある項目数
\(\max(\cdot,0)\) … 減った分だけを消失、増えた分だけを獲得として数える

正の部分だけを取ることの意味

差をそのまま平均すると、減った項目と増えた項目が打ち消し合う。消失と獲得は別々に起きうる現象なので、片方ずつ正の部分を取り出している。この定義は原集計値を再現しており、Pearson 相関で \(r=0.999\) である。

4定義と仮定

代用が成り立つために、何を置いているか。

観測されるのは世代差、主張したいのは時間変化である。両者を結ぶには次の仮定が要る。

  1. 言語の安定性　個人の言語は一定の年齢を過ぎるとほぼ固定され、その後は大きく変わらない。高年世代の言語が過去の状態を保存している、と読めるのはこの仮定による。
  2. 年齢による使い分けがない　世代差が、変化ではなく「その年齢ではそう話すもの」という規範の反映ではないこと。これが破れる現象を Age-grading という。第6節の主題である。
  3. 集団の連続性　高年世代と若年世代が、同じ言語共同体の異なる時点を代表していること。大規模な転入や転出があれば、世代差は変化ではなく集団の入れ替わりを映す。

この研究での標本の作り方

米原市3学区・関ケ原町2学区で2015年11月21日から12月20日に実施された方言調査から、中学生544名と60歳以上142名を用いている。40〜50歳のコホートを除外して、対比を最若年世代と最高年世代のあいだに置いた。「高年世代」は年齢（60歳以上）で定義したものであり、参加した中学生の血縁上の祖父母とは限らない。

世帯内の非独立性は排除できていない

調査は地域を単位として実施され、どの回答者とどの回答者が同じ世帯かという情報を持たない。同居する祖父母と孫が両方回答している可能性があり、その場合、両者の言語は独立な2つの観測ではない。この点は限界として明記されている。

5この研究での使い方

世代差として測った消失を、集落ごとの人口動態に対して回帰する。

  1. 語彙の設計　40の質問概念で106の方言語彙変異を引き出し、関西・近江系45、東京・標準31、美濃・尾張系26、若者/新方言4項目に事前分類する。
  2. 消失・獲得の算出　第3節の定義で集落ごとに算出する。両世代のデータが揃う25集落が解析対象になる。
  3. モデル化　消失・獲得をベータ分布（logit リンク）でモデル化し、標準化した人口成長率、log中学生標本、log高年標本を予測変数とする。中学校区（5区）をランダム切片に置く。
  4. 推定　弱情報事前分布のもと brms と Stan で推定する。傾きに Normal(0,1)、切片に Normal(0,2)、精度 \(\phi\) に Gamma(0.1,0.1)。
  5. 人口成長率の定義　2010年の集落人口を2005年で割った比を用いる。これは移住や住民の入れ替わりを直接測ったものではなく、近年の人口変化の代理である。

観測しているものと推論しているものを分けて書く

人口成長率は観測値だが、それが意味する住民の入れ替わりは推論である。この研究は両者を明示的に分けて記述しており、人口成長という観測を、集団の連続性という仮定の検証材料としても使っている。

6限界 ―― Age-grading をどう切り分けるか

世代差が変化ではなく、年齢に応じた使い分けである可能性。

この手法の最大の弱点は Age-grading（年齢段階効果）である。若いときには若者らしい言い方を使い、年を取ると改まった言い方に移る。この場合、同じ世代が加齢に伴って話し方を変えているだけであり、共同体の言語は変化していない。それでも横断調査では世代差として観測される。

観測だけからは、世代差が変化の途中なのか、年齢による使い分けなのかを区別できない。2つの解釈が同じデータを生むからである。ここが、この手法を因果の観点に置くべき理由でもある。

2つの解釈が予測する世代パターンの違い
\[ \underbrace{\beta_{\text{old}} > \beta_{\text{middle}} > \beta_{\text{pupil}}}_{\text{変化進行中なら単調}} \qquad\text{に対して}\qquad \underbrace{\beta_{\text{middle}} \not\in \bigl(\beta_{\text{pupil}},\,\beta_{\text{old}}\bigr)}_{\text{年齢段階効果なら非単調}} \]

中間世代を加えると、2つの解釈は異なる形を予測する。変化が世代を追って進んでいるなら、効果は世代順に単調に動く。年齢による使い分けなら、中間世代が両端の外に出る形（逆U字など）になりうる。

この研究での切り分け

30〜59歳の中間世代211名を加え、3世代が揃う21集落で世代×人口成長の交互作用をモデル化している（lme4、観測レベル変量を入れた二項モデル）。人口成長の世代別の傾きは次のとおりである。

世代成長の傾き標準誤差
高年（60歳以上）+0.0490.170
中間（30–59歳）−0.0530.170
中学生−0.1840.168

数値は 23_three_gen_model.R の出力 three_gen_summary.txt から引用。各傾きは個別には有意でない。

読み方 ―― 個々の有意性ではなく、順序

高年から中間、中学生へと傾きが単調に下がっている。高成長の集落ほど、若い世代ほど当該語彙の使用が低い。この形は変化が世代を追って進んでいるという読みと整合し、年齢段階効果だけでは説明しにくい。ただし各推定の標準誤差は約0.17で、個々の傾きはいずれも有意ではない。主張の根拠は個別の有意性ではなく、3点が示す順序のほうにある。

これは Age-grading を排除した証明ではない

単調性は、変化進行中という解釈と整合するというだけであって、年齢段階効果が働いていないことを示すものではない。両方が同時に起きている可能性も残る。決着をつけるにはリアルタイム調査が要り、それができないからこそ見かけ上の時間法を使っている、という循環がここにある。

この研究はその点を隠さず、Introduction で apparent-time の採用と age-grading への留保を併記し、限界の節でも明示している。代用であることを認めたうえで、代用が破れる方向を別のデータで確かめるというのが、この手法に対して取りうる最も誠実な姿勢である。

7出典とデータ

言語データは、2015年に市民団体「はびろネット」が米原市・関ケ原町で実施した方言調査による（小野原も調査設計に参加）。873名、地域人口の4.27%を収集している。土地利用は国土交通省の国土数値情報、人口は2010年国勢調査小地域（総務省統計局）、標高は国土地理院の基盤地図情報から取得している。解析は R スクリプトとして手順化され、原データファイルは改変せず作業コピー経由でのみ読む構成になっている。

  • 解析スクリプト：01_prep_data.R（データ整備）、12_brms_loss.R（消失モデル）、23_three_gen_model.R（3世代モデル）ほか。
  • 関連する研究系譜：2016年 地理情報システム学会ポスター（言語外要因と語彙得失）、2017–2018年の集団規模と語彙多様性の分析を経て、本解析に至る。

この手法がどの観点に属するか

見かけ上の時間法は、観測された世代差に時間変化という別の解釈を重ねる操作である。同じ観測が Age-grading でも生じうる以上、どちらであるかはデータだけからは決まらず、言語の安定性や集団の連続性という仮定が要る。仮定を置いて初めて変化を語れるという構造は、7つの観点を式で読むの観点7（因果）そのものである。そこに書いた「処置の割り当てが結果と独立であることは観察データでは仮定であって検証できない」という一文が、この手法にもそのまま当てはまる。

このページは、小野原が実際の研究で使っている手法を、同じ分野の読み手に向けて整理したものです。数値はすべて解析スクリプトの出力から引用し、推定値や概算は記載していません。
