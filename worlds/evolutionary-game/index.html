観点 6 ｜ ゲーム・敵対

Invasion and Fixation

ある状態が可能であることと、集団がそこへ運ばれることは別の主張です。進化ゲーム理論は後者を扱い、パラメータだった量を戦略に変えて、利得の差が増殖率に変換される過程を回します。
小野原が「判定の仕方そのもの」を戦略にしたモデルに即して、軌跡・侵入適応度・固定確率の三つをどう使い分けたかを整理します。

1何のための手法か

パラメータを戦略に変えて、「その状態は選ばれるのか」を問う。

力学系の分析は、ある条件が成り立てば何が起こるかを答える（折り畳み分岐）。しかし条件に出てくる量が人の振る舞い方であるなら、次の問いが残る。集団はそこへ運ばれるのか。放っておけばその状態に近づくのか、それとも近づかないのか。

進化ゲーム理論はこれを扱う。これまでパラメータだった量を個体が持つ戦略に変え、利得の高い戦略が広がる過程を書く。問うのは最適化ではなく、ある戦略を持つ少数者が多数者の中で増えるかどうかである。生物学では血縁選択や協力の進化を扱うために作られた枠組みだが、ここでは判定の仕方そのものが戦略になる。

小野原の使い方には、この枠組みの標準的な使い方からの差分がひとつある。普通は「協力するか／しないか」が戦略である。ここでは協力するかどうかは戦略ではなく、他人の判断をどれだけ重く読むか（\(\eta\)）と判断をどれだけ範疇的にするか（\(k\)）が戦略である。どちらも道徳的な性質ではなく推論の仕方であり、その積が分岐条件に現れる量である。

2利得は二つの成分からなる

正確さが規律し、同調が膨らませる。両方を一つの式に入れる。

各個体 \(j\) は \((\eta_j,k_j)\) を持ち、私的な手がかりと、相手がいま受けている支援から \(r_{ji}\) を作り、確率 \(\sigma(k_j(r_{ji}-\theta))\) で支援する。利得にはちょうど二つの項を置く。

利得
\[ \pi_j \;=\; \underbrace{S_{ji}\,(b\,a_i - c)}_{\text{認識的}}\;-\;\underbrace{w\,\big|S_{ji}-\bar s_{-j,i}\big|}_{\text{二次的}} \]

認識的な項 … 支援が支援に値する人に届いているか。\(c = b\theta\) と置くので、\(\theta\) はちょうど支援が損得なしになる貢献にあたる
二次的な項 … 集団の評決から外れることのコスト。\(w\) がその強さ
\(S_{ji}\) … \(j\) が \(i\) を支援したか（0 か 1）
\(\bar s_{-j,i}\) … \(j\) 以外が \(i\) をどれだけ支援しているか

二つの項は反対方向に引く

第一項は \(\eta\) を規律する。群衆を重く読みすぎれば判断が悪くなり、罰される。第二項は \(\eta\) を膨らませる。判定者自身の立場も同じ機械で決まるので、周囲が見切った相手を支援すれば判定者として見る目がないと見なされ、周囲が支援している相手に渋れば薄情と見なされる。どちらに転ぶかが、この節の問いである。

第二項は既存の機構の縮約形である

間接互恵性を進化的に安定にするのは、「値しない者に与えない、さもなくば自分が値しない者になる」という二次的な要求である（Panchanathan & Boyd 2004）。その機構ではコストは内部的で、外れた判定者は立場を失い、その結果として支援を失う。上の式はそれを利得から直接引いている。縮約形であることは弱点になりうるので、第7節でループを閉じ直して何が残るかを報告する。

3起源 ―― 有限集団の進化動態

無限集団の微分方程式ではなく、有限集団の確率過程として扱う。

ペアワイズ Fermi 模倣

個体 \(i\) が個体 \(j\) を真似る確率を \(\sigma(\beta(\pi_j-\pi_i))\) とする。\(\beta\) は淘汰の強さで、\(\beta\to0\) なら中立なドリフト、\(\beta\to\infty\) なら常に高利得側を真似る。統計物理の Fermi 分布から来た形で、有限集団の進化動態の標準的な更新規則になっている。ここでは変異として \((\eta,k)\) にガウス雑音を加え、\(\eta\in[0,6]\)、\(k\in[0.1,30]\) で境界を切る。

有限集団では「安定」の定義が変わる

無限集団の ESS は「侵入適応度が負」で定義される。有限集団ではドリフトがあるため、不利な変異体も確率的に固定しうる。そこで Nowak ら (2004) は基準を置き換えた。定住者 \(R\) が変異体 \(M\) に抵抗するのは、単一の \(M\) 変異体が中立な変異体より固定しにくいとき、すなわち \(\rho_M<1/N\) のときである。

固定確率
\[ \rho_M=\Big[1+\sum_{k=1}^{N-1}\exp\Big(-\beta\sum_{j=1}^{k}\Delta\pi(j)\Big)\Big]^{-1} \]

\(\Delta\pi(j)\) … 変異体が \(j\) 個いるときの、変異体と定住者の期待利得差
導出 … ペアワイズ比較の更新では遷移確率が \(T^-(j)/T^+(j)=\exp(-\beta\Delta\pi(j))\) を満たすので、この形になる
読み方 … 利得差を経路全体に沿って足し上げる。一世代あたりの小さな差が経路上で積み上がるので、margin は大きくなる

4三つの基準を使い分ける

軌跡は初期値に依存する。安定性の主張は軌跡に載せられない。

この研究では三つの測り方を併用し、何をどちらに載せるかを分けている。順に、強いことを言えるものではなく、何に依存するかで並べる。

  1. 軌跡　初期戦略から淘汰と変異を回し、400世代後の \(\overline{k\eta}\) を見る。初期値に依存する。中立な対照（\(\beta=0\)）を同じ初期値から並走させないと、淘汰の効果とドリフトの効果が区別できない。
  2. 侵入適応度の符号　定住者と少数の変異体を固定し、平均利得差の符号を見る。初期値に依存しない。有意性ではなく符号で判定する——有意にならないセルは検出力が低いだけであり、進化的双安定が要求するのは両方の侵入適応度が負であることだから。
  3. 固定確率　式 (7) を \(\Delta\pi(j)\) の全範囲について評価し、\(1/N\) と比べる。初期値に依存しない。有限集団の確率過程についての標準的な定義そのもの。

軌跡の水準は初期値の産物だった

同じ掃引を別の初期戦略から回すと、\(w=0\) で選ばれる \(\overline{k\eta}\) は \((\eta_0,k_0)=(0.2,4)\) から 2.89（中立対照 1.53）、\((1.0,4)\) から 4.26（対照 3.97）、\((3.0,4)\) から 7.01（対照 11.15）、\((0.2,10)\) から 4.85（対照 3.88）、\((3.0,10)\) から 29.63（対照 29.13）になる。\(\eta_0=3\) から始めると、選ばれた値は自分の中立対照以下である。400世代のドリフト律速な模倣では、集団は始めた戦略から戻ってこない。

境界の処理も確認した。クリップを反射に替えると \(w=0\) で 2.89 から 3.03、\(w=0.5\) で 5.88 から 5.92 に動くだけである。どの初期値でも両方の境界規則でも残るのは \(w\) 自身の効果で、2.89→5.88、4.26→8.90、7.01→14.48、4.85→8.76 と一貫して上げる。そこで軌跡の表は「二次的コストが集団を動かす方向の例示」と位置づけ、安定性の主張は侵入と固定の分析に載せ替えた。

淘汰の強さが足りないと、最適点に届かない

\(\beta=6\) では利得差が \(0.01\)–\(0.08\) の程度で、模倣確率は \(0.515\) 付近に留まる。集団は最適点ではなくドリフトに律速されている。淘汰を効率的にすると（\(\beta=30\)、\(w=0\)）、認識的な項だけですべての反復が折り畳みを越え、\(\overline{k\eta}=5.13\pm0.76\) に達する。正確な判断への見返りは折り畳みの手前で尽きるのではなく、折り畳みのすぐ先で尽きる。独立に測った淘汰勾配の零交差（\(k=7\) 固定で \(\eta^\ast\approx0.62\)、すなわち \(\overline{k\eta}^\ast\approx4.4\)、閾値 4.0 の8パーセント上）と整合する。勾配の推定に使った変異体のずらし幅 0.25 は分岐をまたぐので、これは格子幅 0.13 までの精度で「折り畳みのところ、わずかに上」と読むべきで、点推定ではない。

5期待利得の過程と実現利得の過程は別物である

同じ更新規則の名前で呼ばれる二つの過程が、同じ答えを返す必要はない。

式 (7) の導出に使った恒等式 \(T^-/T^+=\exp(-\beta\Delta\pi)\) は、二つの戦略の期待利得についてのペアワイズ比較で成り立つ。これが基準の標準的な設定であり、評価しているのもこれである。一方、軌跡のシミュレーションでは、各模倣イベントが二個体の実現利得を比べている。

二つが一致しない理由
\[ \mathbb{E}\big[\sigma(\beta D)\big] \;\neq\; \sigma\big(\beta\,\mathbb{E}[D]\big) \]

\(D\) … 実現利得の差。分散が正であれば等号は成り立たない
帰結 … 貢献の個体差が利得に雑音を加え、実現利得の過程では淘汰のバイアスが弱まる。二つの過程は行ごとに一致する必要がない

なぜこれを明記するか

固定確率の表と軌跡の表が食い違うとき、どちらかが間違っていると読まれる。実際には別の量を計算している。固定確率の表は標準的な基準を標準的な過程に適用したものであり、軌跡を固定まで走らせたらどうなるかの計算ではない。速度と安定性の違いに加えて、これが両者が行ごとに一致しなくてよい第二の理由である。

6この研究での結果

二次的コストが閾値を越えると、切り替わる。双安定帯は現れない。

二通りの侵入テストを \(w\) について並べる。「抵抗する」は、比較した相手の変異体に侵入されないという意味であり、\((\eta,k)\) 空間全体に対する進化的安定性ではない。

外れた予測：双安定帯はなかった

二つのレジームがそれぞれ相手に抵抗する帯——同じ \(w\) でどちらの状態も自分を守れる領域——を予期していたが、見つからなかった。調べたどの \(w\) でも両方の侵入適応度が負になることはない。\(w=0.10\)–\(0.12\) の中間領域は、双安定の逆で、どちらも相手に抵抗しない領域である。切り替えは \(w\approx0.14\) で完了する。

これは集団間の比較から何が言えるかに関わるので、本文に明記した。比較した二つの判定戦略について、調べた \(w\) の範囲で、他の生態を固定したうえでは、互いに抵抗する一対のレジームは観察されなかった。これは判定規則における経路依存性の余地を限定するが、排除するわけではない——別の戦略対、混合状態、調べた値の間の \(w\)、長い過渡状態のいずれでも生じうる。したがって二集団のレジームの違いは \(w\) の違いと整合するが、\(w\) の違いを同定しない。

重要なのは、これが戦略についての主張であって結果についての主張ではないことである。折り畳み分岐と支援行列の分析が示すのは、\(\eta qk>4\) ならどこでも支援行列が双安定だということで、同じ集団の同じ個体が別の側に落ち着きうる。双安定帯の不在が限定するのは、判定規則の経路依存性であって、誰が包摂されるかの経路依存性ではない。

固定確率の基準も同じ結論を返す

\(N=150\)、\(\beta=6\) で中立値は \(1/N=6.7\times10^{-3}\)。\(w=0\) では範疇的な単一変異体の固定確率が \(2.7\times10^{-7}\)、段階的な単一変異体が \(1.8\times10^{-1}\) で、段階的が抵抗する。\(w=0.60\) では \(1.0\times10^{-1}\) と \(5.2\times10^{-22}\) で逆転する。切り替えは両方の基準で 0.10 と 0.15 の間に落ちる。両方の確率が \(1/N\) を下回る行はひとつもなく、どの行でもちょうど一方が下回る。\(\beta=30\) で繰り返しても、\(\Delta\pi(j)\) を17点格子からの内挿ではなく全 \(j\) で評価しても、判定は変わらない。

コストは \(\eta\) に効き、\(k\) には効かない

第二項には別の読み方がありうる。\(S_{ji}\) が二値で \(\bar s\) が連続なので \(\mathbb{E}|S_{ji}-\bar s|=2p(1-p)\) となり、これは \(p=1/2\) で最大、\(p\) が飽和すると消える。この形のコストは、誰の評決にも従わずに支援パターンを先鋭化する（\(k\) を上げる）ことで払い下げられてしまう。実際にはそうならない。\(w\) を 0 から 1.2 まで動かすと \(\eta\) は 0.415 から 1.355 へ3.3倍になるが、\(k\) は 6.990 から 8.069 へ1.15倍にしかならない。二次的コストは、主張されている機構どおり、共同体の評決に置く重みに効いている。

淘汰は集団の最適点を通り過ぎる

認識的な成分だけ——支援が支援に値する人に届いているか——を測ると、\(k=7\) 固定の \(\eta\) 掃引で最適は折り畳みのところ（\(k\eta=3.99\) で \(0.0836\pm0.0096\)）にあり、その先では \(k\eta=7.00\) で \(0.0723\)、\(10.5\) で \(0.0369\)、\(21.0\) で \(-0.0137\pm0.0118\) と下がる。精度も \(.987\) から \(.504\) へ落ちる。

ただし利得は \(k\eta\) の関数ではない。支援確率は \(\sigma\{k(x-\theta)+(k\eta)\bar s\}\) なので \(k\) は私的情報の重みも決める。積を \(k\eta=10.5\) に固定して \(k\) を 3.5、7、14、21 と振ると、利得は \(-0.0130\)、\(0.0369\)、\(0.0836\)、\(0.0869\) と表全体の幅にわたって動く。分岐条件が依存するのは積だが、利得は積の関数ではない。したがって読むべき場所は格子ではなく実際に進化した戦略である。表9 が報告する6対（\(k\) は 6.99 から 8.07 へ上がる）で測ると、利得は \(0.0829\)、\(0.0840\)、\(0.0836\)、\(0.0789\)、\(0.0657\)、\(0.0478\)（標準誤差 \(0.0092\)–\(0.0118\)）となる。淘汰が実際にたどる経路では、最適は \(w=0.20\) と \(0.30\) で進化した対——折り畳みのすぐ先——にあり、調べた最大の \(w\) ではそこから約五分の二まで落ちるが、ゼロには達しない。淘汰がするのは最適点を通り過ぎることであって、利益を消すことではない。

7縮約形を内生化する

利得から直接引くのをやめ、モデル内の機構でループを閉じる。

式 (6) は外れた判定者の利得を直接引く縮約形である。それが代理している機構では、判定者は立場を失い、その結果として支援を失う。モデルはすでに立場を割り当てる機械を持っているので、仮定する代わりにループを閉じられる。

内生化した二次的コスト
\[ a^{\text{eff}}_j = a_j - w\,d_j,\qquad d_j=\overline{\big|S_{jl}-\mathbb{1}[\bar s_{-j,l}>1/2]\big|\cdot\big|2\bar s_{-j,l}-1\big|} \]

読み方 … 共同体が明確に見切った相手を支援すること、明確に支援している相手に渋ることが \(j\) の不利になり、境界的なケースはほとんど数えない
肝 … 他者は \(a^{\text{eff}}_j\) について \(j\) を全員と同じ規則で判定する。利得への罰則はどこにもない

三つが引き継がれ、二つが変わる

引き継がれるもの。コストは依然として \(\eta\) に効いて \(k\) には効かない（\(w\) を 0 から 3 へ動かすと \(\eta\) は 0.467 から 0.885、\(k\) は 6.450 から 7.191）。レジームは依然として段階的が抵抗する側から範疇的が抵抗する側へ切り替わる。そして依然として両方の侵入適応度が負になる \(w\) は存在しない——双安定帯の不在は縮約形の産物ではない。

変わるもの。閾値が \(w^\ast\approx0.13\) から \(w^\ast\approx0.6\)–\(0.8\) へ動き、同程度の \(w\) での効果の大きさは約三分の一になる。利得から直接引く定式化は、評判の経路が実際に届けるものを過大評価している。これは知っておく価値があり、節の結論は変えない。なお内生形では \(w=0.5\) で両方の固定確率が \(1/N\) を超える（\(2.4\times10^{-2}\) と \(5.2\times10^{-2}\)）——双安定が崩れるもう一つの形、つまりどちらも抵抗しない場合である。

8記録しておく二つ目の負の結果

効果が見えないことと、機構がないことは違う。

\(v\) 依存性は実在するが、貢献の雑音に隠れている

異議のコストは \(v\)——包摂されていることの価値——に比例して増えるはずである。進化の掃引ではそうならない。\(w=1\) で \(v\) を 0.1 から 2.0 まで動かすと \(\overline{k\eta}\) は 3.99、3.58、4.13、5.03、3.80 で、反復のばらつきの中で平坦から非単調である。

機構がないからではない。侵入テストのように \(a\) を固定すると、範疇的な変異体と段階的な定住者の利得差の立場成分は \(v\) に厳密に線形で、\(v=0.1\) の \(7.3\times10^{-4}\) から \(v=2\) の \(1.45\times10^{-2}\) へ増える。しかし同時に、戦略内の利得のばらつきも増える。それはほぼすべて \(a_j\) から来ており（定住者内での利得との相関は 0.98–0.99）、大きさは30倍、同じ範囲で 0.022 から 0.44 になる。\(a_j\) は毎世代引き直され、戦略についての情報を持たない。つまり \(v\) を上げることは、二次的な信号を足すのと同じ速さで淘汰の信号に雑音を足している。

これは操作で確認できる。\(\sigma_a\) をゼロにすると模倣バイアスは 0.010、0.026、0.051、0.101、0.194 と \(v\) に伸びるが、論文の \(\sigma_a\) では 0.002、0.010、0.021、0.033、0.042 で \(v\approx1\) で平坦化する。\(\sigma_a=0.15\) と \(0.05\) では軌跡も \(v\) について単調になる。\(v\) 依存性は実在するが、論文の \(\sigma_a\) では貢献の雑音に覆われている。これが見えるのは \(a\) を固定して群を揃える侵入分析であり、結論が載っているのもその分析である。

不均質な集団では \(\overline{k\eta}>4\) は必要条件にすぎない

判定者が均質なら集団は \(\overline{k\eta}>4\) で折り畳む。不均質な判定者では、自己無撞着写像の最大傾きが \(N^{-1}\sum_j k_j\eta_j\,\sigma_j(1-\sigma_j)\le\overline{k\eta}/4\) になり、等号は全判定者が同時に自分の変曲点にいるときだけ成り立つ。したがって \(\overline{k\eta}>4\) は必要条件であって十分条件ではなく、表の「折り畳みを越えた反復の割合」は上限として読むべきである。同じ不等式はロジスティック縮約の測定可能性の議論にも効いている。

この手法がどの観点に属するか

観点6 が扱うのは「複数の主体がいて、各自の選択が他者の結果を左右する」構造である。この観点には既に二つの手法が置かれている。敵対的生成ネットワークの \(\min_G \max_D V(D,G)\) は零和で、プレイヤーは2つのネットワークであり、解は釣り合った点である。経済ゲームは非零和で、プレイヤーは生身の人間であり、解は観察された選択の分布である。

この手法は三つ目の型になる。プレイヤーは集団で、解はどの戦略が時間とともに広がるかである。釣り合いを解くのでも選択を観察するのでもなく、利得の差が増殖率に変換される過程を回す。ゲーム理論の「均衡」ではなく、進化動態の「固定」が答えになる。8つの観点を式で読むの観点6（ゲーム・敵対）に、この手法が置かれている。
